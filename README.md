# Controls Engineering — PLC / SCADA / HMI Portfolio

Hands-on industrial controls work: PLC ladder logic, SCADA/HMI design, and
process-automation projects. Built by a mechatronics + commissioning engineer
moving deeper into the controls/automation side — pairing real field
commissioning experience with programmed control logic.

## What this repo demonstrates
- **PLC programming** — ladder logic / structured control for real process sequences
- **SCADA / HMI** — operator screens, tag design, alarming (Ignition)
- **Systems integration** — sensors → controller → actuator → visualization
- **Commissioning mindset** — I/O checkout, functional testing, and validation
  of control logic against real equipment behavior

## Structure
```
/ladder-logic     PLC programs (with commented rungs + I/O maps)
/scada-hmi         Ignition / HMI screens + tag configs
/process-notes     Control narratives, sequence-of-operation writeups
/test-validation   I/O checkout sheets + functional test records
```

## Background
Mechatronics background; currently a commissioning engineer applying that
field experience to programmed automation. This repo tracks the controls
projects I'm building — each one framed the way it would be in industry:
requirements → control narrative → logic → test/validation.
